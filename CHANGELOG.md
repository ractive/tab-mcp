# Changelog

Each package has its own changelog, released on its own with its own Git tags. The two
npm packages ship theirs in the package (`node_modules/<package>/CHANGELOG.md`).

- [@ractive-ch/tab-mcp-client](packages/tab-mcp-client/CHANGELOG.md): the browser
  library, tags `client-v<version>`.
- [@ractive-ch/tab-mcp](packages/tab-mcp/CHANGELOG.md): the relay and its Docker image,
  tags `relay-v<version>`.
- [tab-mcp browser extension](packages/tab-mcp-extension/CHANGELOG.md): the browser extension,
  tags `extension-v<version>`.
